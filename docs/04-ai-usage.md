# AI 使用与个人贡献

| 参与方 | 实际工作 |
| --- | --- |
| 项目作者 | 选择国内差旅场景，确认适用范围、制度数值、追问和冲突处理规则，配置模型密钥，提出终端排版、等待动画和即时菜单的改进要求，并亲自复核交互与指定 Trace。 |
| Codex | 辅助澄清需求、起草合成制度和方案，编写代码与测试，执行 CLI，保留失败并复核三轮真实记录，整理文档。代码实现与三轮逐例核查由助手完成。 |
| DeepSeek | 真实模式通过工具调用选择检索、读取、追问或结束，根据实际返回结果调整后续动作。离线 Mock 由本地规则生成动作。 |

## 作者的实际验证

作者反馈亲自操作菜单、住宿追问及 Ctrl+C，结果符合预期。作者对照正常检索补测与首次检索模拟超时的两份真实 Trace，确认正常检索返回候选文档，超时返回 search_timeout；模型随后换关键词重新检索，找到 D01 后读取原文并回答，报销期限和引文与 D01 一致。

上述个人验证依据为作者自述。作者独立改码和全部场景逐条人工核查尚无记录。个人投入约 90 分钟，其中本次操作复核自述 30 分钟、早期估算一小时。助手执行计时另列于复盘，项目总历时无法精确计算。

## 验证边界

所有业务材料均为合成制度。Trace 记录动作、简要依据、工具参数及结果。模型决策效果引用真实运行，离线测试验证协议校验、故障注入和本地流程。三轮评估为 3/6、4/6、5/6，正常组后续补测单列，失败和措辞限制见 [评估报告](03-evaluation.md)。
